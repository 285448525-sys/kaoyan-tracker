☁️ 云端同步（登录码）

用一个「8 位登录码」把数据同步到 Cloudflare KV。相同登录码可在任意设备拉取同一套数据。

首次使用建议先点「导出备份」把本地数据存一份，再做云端操作；从云端下载会覆盖本机全部数据，下载前会弹窗二次确认。

🔑 翻译 API 密钥（自行申请填写）

翻译功能由你自己的百度翻译开放平台账号调用，密钥仅保存在你本机浏览器，网站不内置任何 key、也不上传服务器。申请后把 APP ID 与 密钥填到下方即可使用「即时翻译」。

申请地址：百度翻译开放平台（fanyi-api.baidu.com），开通「通用翻译 API」后获取 APP ID 与 密钥。申请时请把你电脑的出口 IP 加入 IP 白名单（或设为不限），否则会返回 58000 错误。配置好后点「测试连接」验证。
