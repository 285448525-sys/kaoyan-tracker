 4→一、如何打开
 5→══════════════════════════════════════
 6→直接双击本文件夹里的 index.html 即可在浏览器中使用。
 7→无需安装任何软件、无需启动服务器、无需联网（除“翻译”功能外）。
 8→所有学习数据（计时、笔记、错题、生词、计划、模考成绩等）都只保存在
 9→你当前这台电脑的浏览器“本地缓存（LocalStorage）”里，不会上传到任何服务器或云端。

12→二、关于翻译功能（重要）
13→══════════════════════════════════════
14→1. 翻译想要生效，必须自己去申请 API key 并填写进设置框。
15→   · 申请地址：百度翻译开放平台 https://fanyi-api.baidu.com
16→     开通「通用翻译 API」后，即可获得 APP ID 与 密钥（Secret Key）。
17→   · 在网站「配置」页把 APP ID 与 密钥填进去，点“保存密钥”即可使用“即时翻译”。
18→   · 密钥只保存在你本机浏览器里，网站不内置任何 key，也不会上传。
19→   · 申请时请把你电脑的出口 IP 加入百度翻译的 IP 白名单（或设为“不限”），
20→     否则翻译会返回 58000 错误。
21→   · 没填密钥时，“翻译并归档”按钮是灰色的不可用状态，其他功能完全不受影响。
22→
23→2. 学习记录只存在浏览器本地，清除缓存就会丢失。
24→   · 换浏览器、换电脑、或清除浏览器缓存 / 网站数据，记录都会消失。
25→   · 重要数据请定期用「配置」页的“导出备份”保存成 .json 文件；
26→     换设备后用“导入备份”恢复。

29→三、打包分发注意事项
30→══════════════════════════════════════
31→· 本文件夹是纯静态站点，可整体压缩（zip）后发给他人；对方解压后
32→  双击 index.html 即可使用，同样无需启动服务、无需安装依赖。
33→· 请勿改名或删除 index.html 内引用的文件（styles.css / app.js /
34→  store.js / charts.js / share.js / sentences.js / words.js / md5.js /
35→  使用说明.txt），否则页面会加载失败。
36→· 翻译功能依赖使用者自己申请的百度翻译 key，分发时不含任何密钥。
37→· 不同用户、不同浏览器之间的数据互不可见（各自存在各自本地）。
