## ① 目标

### 用户视角要解决的问题

考研党每天打开这个站 3–6 次，每次 30 秒–20 分钟，手机为主。首页要在一眼之内回答三个问题：

1. **今天学多久了？离目标还差多少？**
2. **现在想学，从哪儿开始？**
3. **今天还剩什么事没做？**

### 实测发现的三个真问题（基线证据）

| # | 问题 | 实测证据 | 影响 |
| --- | --- | --- | --- |
| 1 | **桌面端溢出视口**（违反红线） | 1280×800 下页面 `scrollHeight=832px` > 视口 800px；移动端 375×812 下 `scrollHeight=1048px`（超出 236px） | 首屏「开始计时」按钮被推到需要滚动的位置，与「一屏不滚」红线冲突 |
| 2 | **同一数字说两遍** | `#m-stat-todo` 显示「1/3」+ 标签「今日待办」；紧邻下方 `#home-todo-sub` 又显示「1/3 完成」，两者相距约 130px | 视觉噪音，用户以为其中一个是别的指标 |
| 3 | **待办列表被裁切形成嵌套滚动** | `.plan-list` `max-height:168px` 而 `scrollHeight=191px` → 内容被截断，内部又出现一条滚动条 | 列表底部内容（含添加框）被压，用户在页中页里滚动 |

补充观察（非缺陷，仅记录）：三个统计卡用的是 Memphis 糖果色蓝 `#3DA5FF` / 绿 `#3DD68C` / 紫 `#9B6BFF`，与主色暖橙 `#EA580C` 无色彩关系。HANDOFF 记录糖果色是**用户显式授权**的，因此本方案不擅自取消，而是给出 A/B 两条路（见 ③）。

### 不做什么（红线）

- 不动 Store 层、其他 tab 渲染、侧栏/底部导航结构
- 不改 token 定义（`--primary` 族、间距、圆角一律沿用现有值）
- 不新增浮动元素（用户约定：新增浮动/交互元素默认会被砍）
- 不折叠首页内容（`<details>` 仅允许用于待办添加表单，本方案也不折叠）
- 保持所有现有 `id`/`data-goto`/事件钩子不变 → A 窗口只改结构与样式，风险可控

## ③ 方案 A / B（预览原型可切换）

两方案**结构相同**，只在「三个统计卡的用色」上分叉。其余改动（合并 CTA、去重、限高）两案共有。

### 共同改动（A、B 都做）

1. **「开始计时」并入 Hero 卡右侧** —— 现在是 Hero 卡（142px）+ 独立 CTA 行（50px）+ 间距 ≈ 210px。合并后 Hero 卡内左侧放数字、右侧放主按钮，省下约 60px，且「数字 + 动作」语义上本就该在一起。移动端按钮降为全宽置于卡底。
2. **去掉重复的待办计数** —— 保留 `#home-todo-sub`（「1/3 完成」）在区块标题右，删除统计卡里的「今日待办」卡，改为第三个指标换成**「今日专注达标率」或「连续学习」**（原连续学习已在其中）。最终三个指标：**本周专注（分）/ 连续学习（天）/ 今日目标达成（%）**，各指标口径全部来自 `workspace.js renderStats()`，不新增写入方。
3. **待办列表限高改为「按行数」而非固定 px** —— 桌面显示 4 行、移动 3 行为上限，超出显示「还有 N 条」并可展开（不折叠整块，只展开列表）。消除嵌套滚动条。
4. **压缩垂直节奏** —— 头部问候区去掉桌面端装饰性留白；语录在小屏隐藏（装饰性内容让位于行动区）。

### 方案 A：收敛暖色（推荐）

三个统计卡改用暖橙家族的同族不同深浅 + 语义色，构成「温度递减」而不是「三个不相干色块」：

| 指标 | 底色 | 数字色 | 理由 |
| --- | --- | --- | --- |
| 本周专注 | `--primary-soft` `#FFF1E6` | `--primary-strong` `#C2410C` | 最贴近主色，突出「投入」 |
| 连续学习 | `--primary-soft-2` `#FDEFE2` | `--primary-deep` `#9A3412` | 同族次深，表示「坚持」 |
| 今日目标达成 | `--surface-2` `#F3ECE2` | `--ink` `#1E293B` | 中性底 + 墨色数字，作为「读数」不抢戏 |

优点：主色唯一、克制、接近高级感；缺点：色彩兴奋度降低，成就感提示变弱。

### 方案 B：保留糖果（改动更小）

保留三块糖果色，但**每块只保留一处彩色**（数字或图标），底色统一回 `--card` 白，边框用糖果色 20% 透明：

| 指标 | 强调色 | 说明 |
| --- | --- | --- |
| 本周专注 | 蓝 `#3DA5FF` | 沿用现有授权色 |
| 连续学习 | 绿 `#3DD68C` | 沿用 |
| 今日目标达成 | 紫 `#9B6BFF` | 沿用 |

优点：改动最小、保留用户已授权的视觉记忆点、成就感强；缺点：三色仍与暖橙主色并置，首页暖度被稀释。

> **建议**：A 作为默认展示。若用户希望保留糖果色的兴奋感，B 可立即切换（两案 CSS 差异仅 3 个类）。

## ⑤ 各模块规格

### ⑤-1 顶部问候区 `header.home-header`

| 项 | 规格 |
| --- | --- |
| 位置 | 页顶，与倒计时胶囊同一行（`justify-content: space-between`） |
| 左 | 问候词（`--fs-xs`，`--muted`）→ 昵称（20px / 800）→ 语录（`--fs-sm`，`--muted`，≤600px 隐藏） |

| 高度 | 桌面 ≤ 64px；移动 ≤ 56px |
| 交互 | 胶囊整块可点 → `data-goto="settings"`（不变） |

### ⑤-2 核心行动区 `home-hero-card`（本方案重点）

| 项 | 规格 |
| --- | --- |
| 结构 | 一行两区：**左＝今日专注数字 + 进度条**，**右＝开始计时主按钮** |
| 左区 | 标签「今日专注」（`--fs-sm`，`--muted`）+ 目标（右对齐，`--fs-sm`）→ 大数字 `--fs` 28px/800/`--primary-strong`，等宽数字（`tabular-nums`）→ 副文案「还差 Xh Ym」（`--fs-sm`，`--muted`）→ 进度条（高 8px，胶囊，`--primary` 实底，达标转 `--ok`） |
| 右区 | 主按钮：胶囊，`--primary` 实底，白字，含播放三角；文案「开始计时」/「继续学习」（计时中） |
| 高度 | 桌面 ≤ 92px；移动：按钮移到底部独立一行，总高 ≤ 128px |
| 达标态 | 数字与进度条转 `--ok`，副文案改「已达成今日专注目标」 |
| 数据 | **全部读现有 id**：`#home-focus-num` / `#home-focus-goal` / `#home-focus-sub` / `#home-focus-bar` / `#home-cta-text`；按钮 id 保持 `#home-cta` |

> ⚠️ 唯一需要 A 窗口注意的：按钮从「独立一行」移入卡内后，`app.js` 里对 `#home-cta-text` 的文案写入与对 `#home-cta` 的 `data-goto` 委托都不受影响（都是 id/属性查询，与层级无关）。

## ⑧ 红线（A 窗口执行时不得越界）

1. **不得改** Store 层（`store.js`）、`workspace.js` 的统计写入逻辑以外文件、其他 tab 的 HTML/CSS/JS
2. **不得改** `--primary` 族与间距/圆角 token 的值
3. **不得新增**浮动元素、弹层、Toast 以外的交互
4. **必须保留**全部现有 id：`#home-focus-num` `#home-focus-goal` `#home-focus-sub` `#home-focus-bar` `#home-cta` `#home-cta-text` `#m-stat-week` `#m-stat-streak` `#home-todo-sub` `#home-sys-tasks` `#plan-empty-hint` `#plan-empty-text` `#plan-carry-tip` `#plan-list` `#plan-text` `#plan-subject` `#btn-add-plan` `#btn-auto-plan` `#home-onboard` `#m-quote` `#home-greet-eyebrow` `#home-greet-name` `#home-cd-text` `#home-focus-bar-wrap`
5. **必须保留**统计组唯一写入方纪律：`#m-stat-*` 只允许 `workspace.js renderStats()` 写
6. 改 CSS/JS **必须 bump** `?v=`（三处同步：`index.html` / `app.js APP_VERSION` / `sw.js SW_VERSION`）
7. 不用 emoji 装饰（`⏪` `⚠️` 等状态/语义 emoji 保留）
8. 禁 teal / brown / sage / rose / lavender 等非授权色系
